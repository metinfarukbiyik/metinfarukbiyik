# Metin Faruk Bıyık | Profesyonel Özgeçmiş & Portfolyo

Bu proje, **Metin Faruk Bıyık**'ın profesyonel özgeçmişini, sertifikalarını ve teknik ekipmanlarını sergileyen modern bir web uygulamasıdır.

## 🚀 Teknolojiler

- **React 19** - Kullanıcı arayüzü
- **TypeScript** - Tip güvenliği ve ölçeklenebilirlik
- **Tailwind CSS v4** - Modern ve responsive tasarım
- **Lucide React** - İkon kütüphanesi
- **Vite** - Hızlı geliştirme ve build süreci

## 📁 Proje Yapısı

- `src/components/` - Tekrar kullanılabilir arayüz bileşenleri (Navbar, Footer, Section vb.)
- `src/data/` - Tüm CV, sertifika ve ekipman verilerinin yönetildiği merkez (`cvData.ts`)
- `src/assets/` - Görsel kaynaklar (Profil fotoğrafı ve ekipman görselleri)
- `public/` - Statik dosyalar, favicon ve indirilebilir CV (PDF)

## 🛠 Kurulum ve Çalıştırma

Projeyi yerel bilgisayarınızda çalıştırmak için:

1. Bağımlılıkları yükleyin:
   ```bash
   npm install
   ```

2. Geliştirme sunucusunu başlatın:
   ```bash
   npm run dev
   ```

3. Üretim versiyonu (build) oluşturun:
   ```bash
   npm run build
   ```

## 🌐 SEO ve Erişilebilirlik

Proje, Google aramalarında ("Metin Faruk Bıyık") ön plana çıkacak şekilde SEO meta etiketleri, `robots.txt` ve `sitemap.xml` ile optimize edilmiştir.
